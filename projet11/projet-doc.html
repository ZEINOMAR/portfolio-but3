Documentation Technique

Objectif du projet

Améliorer les outils internes de l’entreprise POMA en optimisant les scripts backend Python, en modernisant les interfaces web existantes et en développant de nouvelles fonctionnalités pour fluidifier les processus métiers.

Étapes réalisées

  • Analyse des besoins internes avec les utilisateurs métiers
  • Optimisation des scripts Python générant des tableaux de données dynamiques
  • Amélioration des performances de l’API existante
  • Modernisation des interfaces web en HTML, CSS et JavaScript
  • Ajout d’un système de chargement (loader) pour améliorer l'expérience utilisateur
  • Intégration de champs de saisie dynamiques et d’une barre de recherche avancée
  • Rédaction de documentation interne pour la maintenance future

Technologies utilisées

  • Python (scripts backend & API)
  • HTML / CSS / JavaScript (front-end)
  • Optimisation de performances API
  • Gestion de projet en environnement industriel

Compétences acquises

  • Refactoring et optimisation de scripts Python
  • Développement front-end ergonomique
  • Intégration de fonctionnalités automatisées et recherche dynamique
  • Communication avec les équipes métiers et utilisateurs finaux
  • Travail collaboratif en entreprise industrielle
